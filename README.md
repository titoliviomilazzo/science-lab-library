# Science Lab Library

A static library for classroom simulators. Open index.html directly or serve the folder using any static host. The three original self-contained HTML files are in simulations/; their source files are unchanged.

## Add a simulation
1. Copy its HTML into simulations/ and a representative image into images/.
2. Add one entry in catalog.js, with title, description, grades array, subject, topic, duration in minutes, note, image and url.
3. Open the library and verify its filters and link. Use relative paths so it works on GitHub Pages.

Planet Hunter uses synthetic data. The simulations use simplified models; see SOURCE-README.md for the original teaching notes.
